# Site Felipe Sertanejo — versão para subir com arquivos na raiz

Todos os arquivos ficam na MESMA pasta (sem subpastas css/ e js/).
Basta subir todos eles juntos no GitHub / Vercel / Netlify.

## Arquivos
- index.html
- style.css
- responsive.css
- dados-comites.js
- animations.js
- main.js
- favicon.svg

## Fotos (opcional, mas recomendado)
As fotos do Felipe são procuradas em: assets/images/
Se você NÃO criar essa pasta, aparecem placeholders no lugar (o site funciona igual).
Para adicionar as fotos, crie a pasta assets/images/ e coloque:
felipe-hero.jpg · felipe-apoiadores.jpg · felipe-campanha.jpg ·
mockup-celular.jpg · voluntarios.jpg · felipe-institucional.jpg · logo.png

## Como subir no GitHub (corrigindo o problema atual)
1. No seu repositório, apague os arquivos antigos.
2. Suba estes 7 arquivos (Add file > Upload files), todos juntos na raiz.
3. Em Vercel/Netlify, o deploy atualiza sozinho.

Se o CSS não carregar, é quase sempre caminho errado: aqui já está tudo na raiz.
